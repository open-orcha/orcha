15 — Notification acknowledge + clock-wake snooze

Two human controls over when an agent wakes: Acknowledge a single pending notification ("I've seen this — don't wake the agent for it") and Snooze an agent's scheduled clock check-in, neither disabling anything permanently. A per-agent bell + count on the roster, a pending-wakes panel with Acknowledge on every row (web-portal parity) + a confirm-gated Acknowledge all, and a snooze control shown only for clock-configured agents. Two honest scope boundaries: open task-requests / assigned-ready tasks can be acknowledged like any row, but they also carry a deep-link to the real veto and an honest note that the agent keeps waking while the work is open; and snooze pauses only the clock reason — real work still wakes the agent. Mobile equivalent of PR #106 / #89. Every surface ships on real PR #106 endpoints — no new API ask. Spec: notifications/README.md.
