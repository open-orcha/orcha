14 — Scheduled (repeating) tasks

Opt a task into a repeat with a friendly interval picker that honours the server's 60-second minimum; a Repeats badge on the task card; a Schedule section in task detail. The whole feature is one create field (schedule_interval_secs) plus two read fields that ride existing endpoints — firing is server-side, never a client action. Editing / turning off a schedule on an existing task has no route yet and is flagged as new API ask A7. Mobile equivalent of PR #68 / #27. Spec: scheduled/README.md.
