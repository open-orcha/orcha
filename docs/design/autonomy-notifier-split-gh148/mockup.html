Autonomy · Notifier — two separate controls GH #148

One fused 4-rung slider → two orthogonal controls, everywhere. No backend change — both endpoints already exist and are human-only.

Event-notifier · the power switch
Running / Paused. Do agents wake at all? Writes wakes_enabled → POST /wakes.
Autonomy · the gearbox
Plan-only / Build to PR / Full. How far agents go when they act. Writes autonomy_level → POST /autonomy.

Turning the power off never re-shifts the gears — the level is remembered and re-applies on resume. That independence is the whole point of the split.
